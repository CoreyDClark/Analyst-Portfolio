## Projects

### [Project 1: Freight Terminal KPI Analysis](./project-1-freight-terminal-kpi-analysis)
**Tools:** SQL Server (T-SQL), Power BI Desktop

Investigated why one terminal in a 6-terminal freight network was departing late 62% of the time — more than 3x worse than any other terminal. Ruled out capacity strain, isolated the pattern across drivers and shippers, and identified a compounding afternoon-delay effect, backed by a full data-quality validation pass and a Power BI dashboard.

### [Project 3: Inventory Optimization & Demand Forecasting](./project-3-inventory-optimization-demand-forecasting)
**Tools:** Excel (XLOOKUP, SUMIF, statistical formulas)

Built an EOQ, Safety Stock, and Reorder Point model across 150 SKUs, incorporating both demand and lead-time variability. Layered in a moving-average demand forecast and flagged at-risk SKUs for stockout exposure — built to mirror the day-to-day analysis behind a Supply Chain Analyst role.
